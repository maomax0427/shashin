# 写真編集

編集済みのお手本写真（またはインスタなどのスクショ）から雰囲気を読み取ってプリセットを作り、自分の写真に適用できる写真編集 PWA。
処理はすべて端末の中（ブラウザ）で行い、写真はどこにも送信しない。

https://maomax0427.github.io/shashin/

## できること
- お手本 1〜5 枚 → 切り抜き（スクショの余白は自動で外す）→ 雰囲気を読み取ってプリセット化
- Lightroom 風の編集：露光量・コントラスト・ハイライト・シャドウ・白/黒レベル、色温度・色かぶり・自然な彩度・彩度、HSL（8色）、トーンカーブ（全体/RGB）、カラーグレーディング、周辺光量、粒子
- プリセットの強さ（0〜150%）、長押しで元の写真と比較
- 元のサイズ（最大 1600 万画素）で JPEG 書き出し → 共有シートから「画像を保存」
- 複数枚にまとめて適用

## ファイル
- `engine.js` — パラメータと画像処理。GPU（WebGL シェーダー）と CPU の両方に同じ計算を持つ。片方を変えたらもう片方も直す
- `extract.js` — お手本の統計（明るさの分位点、グレー部分の色かぶり、彩度、色ごとの鮮やかさ、周辺減光、粒子）を、無編集写真の平均（`NAT`）と比べ、エンジンの計算で差を再現するスライダー値を探す（Nelder–Mead）
- `app.js` — 画面と操作。保存は localStorage `shashin:v1`
- `tools/eval.js` — 推定の精度評価と `NAT` の較正

## 推定の精度を測る
無編集写真を `meta.json`（`[{name,w,h}]`）と `<name>.rgba`（RGBA 生データ）で置いたフォルダを用意して:

```
node tools/eval.js <dir>            # 既知の編集をかけたお手本から推定し、別の写真での色差（ΔE）を比較
node tools/eval.js <dir> refs=3     # お手本 3 枚の場合
node tools/eval.js <dir> tau=1.5    # 係数を変えて試す
node tools/eval.js <dir> --calib    # NAT を作り直す
```
